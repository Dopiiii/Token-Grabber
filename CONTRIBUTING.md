# Contributing to ATSBOOSTER

Contributions are welcome! This document outlines how to contribute to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/ATSBOOSTER.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test thoroughly
6. Commit: `git commit -m "Add: description of your changes"`
7. Push: `git push origin feature/your-feature-name`
8. Open a Pull Request

## Guidelines

- Keep code clean and follow existing style
- Test your changes before submitting
- One feature per PR — keep PRs focused
- Write clear commit messages
- Update documentation if needed

## Reporting Issues

- Use GitHub Issues to report bugs
- Include OS version, Python version, and error logs
- Describe steps to reproduce the issue

## Pull Requests

- Reference any related issues in your PR description
- Ensure your code builds: `python build.py`
- Be responsive to feedback and reviews
